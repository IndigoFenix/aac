We are using gemini-2.0-flash-exp-image-generation with bidiGenerateContent. Right now, this is the only model with a Live API that has TEXT modality support, which is necessary for our system to work.

2.0 flash models are being retired on March 31 2026.
Before that happens, they will likely add TEXT support to a 2.5 model for the Live API. Keep an eye out for it, or we will need to switch to a different provider.
