אישורי הציות של AWS לגבי חוות השרתים.

## 3. מידע של אקים המועבר לספק — טבלה

⇐AIVOTA: להלן פירוט המידע הצפוי לעבור מאקים לאביוטה במסגרת ההתקשרות. הטבלה משקפת
את היקף השירות המתוכנן ותעודכן בהסכמה הדדית אם היקף ההתקשרות ישתנה. **מובהר כי
אביוטה אינה נדרשת ואינה מבקשת מספרי כרטיסי אשראי, ואינה שומרת מספרי תעודת זהות
של מקבלי השירות עצמם.**

| פריט המידע המועבר | כמות מוערכת | הסבר לצורך העברת המידע (שימוש) | הערות נוספות |
|---|---|---|---|
| שם פרטי ושם משפחה של מקבל השירות | לפי מספר המשתמשים בפועל | זיהוי בממשק הקליני, התאמת לוח התקשורת ופנייה אישית | מוצפן במנוחה; מוצג רק לאנשי צוות מורשים באותו מוסד |
| מגדר ותאריך לידה | כנ"ל | התאמת גיל-שפה, קול, אוצר מילים ותכני למידה; קביעת גיל בגרות לצורך הרשאת הסכמה | תאריך לידה בלבד – לא ת"ז |
| שפה עיקרית ושפות נוספות | כנ"ל | קביעת שפת הממשק, ההקראה ולוח התקשורת | |
| מספר מזהה פנימי של המוסד עבור מקבל השירות | כנ"ל | התאמה בין רשומת אקים לרשומה במערכת | שדה חופשי; אקים קובעת את הפורמט |
| פרטי אנשי קשר (הורה/אפוטרופוס/איש צוות): שם, טלפון, דוא"ל, יחס | 1–4 לכל משתמש | איסוף הסכמה מדעת, שחזור סיסמה, התראות, שיחות וידאו משפחתיות | |
| אסמכתת אפוטרופסות (סוג ההרשאה המשפטית ואסמכתא) – במידת הצורך | לפי הצורך | קביעה מי מוסמך לתת הסכמה עבור בגיר תחת אפוטרופסות, כנדרש בדין | נאסף רק כשרלוונטי |

| מידע קליני/חינוכי: אבחנה, פרופיל תקשורת, יכולת הפקת דיבור, מטרות ויעדים טיפוליים | כנ"ל | בניית תכנית התערבות, התאמת התנהגות הסוכן ומדידת התקדמות | מידע רגיש – סכימה נפרדת ובקרת גישה מוגברת |
| שיוך למוסד/כיתה/מסגרת ופרטי אנשי הצוות המטפלים | לפי מבנה אקים | מידור גישה: איש צוות רואה רק משתמשים המשויכים אליו | |
| תמונות פנים / דגימות קול (אופציונלי, בהסכמה נפרדת) | לפי בחירת המשפחה | זיהוי בני משפחה ואנשי צוות ע"י המערכת, כדי שהסוכן ידע למי המשתמש פונה | מידע ביומטרי – הסכמה ייעודית, ניתן למחיקה עצמאית |
