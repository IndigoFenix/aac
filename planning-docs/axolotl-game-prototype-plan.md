# Axolotl Game Prototype

This will be a virtual pet for the student to interact with and forms the second half of the AAC platform. It is a learning program designed to teach a variety of skills.

For the prototype, create a separate, game screen "above" the main screen. There should be a button above the avatar, and when the user clicks it, the main screen slides down and the game screen scrolls into view.

The game screen consists of a canvas displaying a fish tank with the axolotl avatar in it. Clicking at the bottom should return to the main screen.
