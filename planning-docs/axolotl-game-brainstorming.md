# Learning Games for the AAC Platform

The AAC avatar is presented as an axolotl who can interact with the user periodically in order to help their development. The activities and difficulty will be customized according to the user's capabilities and needs.

## Parameters
- Tank divided into 48 segments where decorations may be placed (8 columns, 6 rows)
  - Hiding spots: Pots, pipes, caves (can hide inside)
  - Plants
  - Rocks

- Food (Different colors)
  - Fish (can grab and feed, motor skills)
  - Pellets (come in many shapes and colors - can ask for specific objects or object + colors)

- Goals
  - Keep axolotl happy, healthy, and fed
  - Needs: Food, sleep, socializing, learning
    - Limiting factor - rejects excess food, gets tired from too much socializing or playing at once.

- When socializing, asks about activities during the day
  - Narrows down what the user wants to talk about






## Feeding Activities
    Communication & Language Goals

    Food Request Game: Axolotl shows preferences through expressions/animations. User must use AAC to "ask" what it wants to eat
    Nutrition Planning: Choose balanced meals using food symbols, building vocabulary and sequencing
    Recipe Following: Multi-step feeding activities that require following visual or text instructions
    Mealtime Conversations: Axolotl asks questions during feeding, encouraging social communication

    Motor Skills

    Precision Feeding: Drop food pellets into specific areas of the tank (fine motor control)
    Food Sorting: Organize different food types by dragging to containers (great for eye-gaze with sequential selection)
    Feeding Schedule: Use calendar interface to plan feeding times (executive function + motor planning)

## Tank Decoration & Environment
    Cognitive Skills

    Pattern Recognition: Arrange decorations in specific patterns the axolotl requests
    Spatial Reasoning: Design tank layouts that meet axolotl's "needs" (hiding spots, swimming space)
    Memory Games: Axolotl "remembers" preferred arrangements and asks user to recreate them
    Color Sorting: Organize decorations by color, size, or type

    Social-Emotional Learning

    Mood Decoration: Choose decorations based on axolotl's emotional state or user's feelings
    Sharing Space: When multiple users, negotiate shared decoration decisions
    Preference Learning: Axolotl develops "personality" preferences based on user choices

## Social Interaction Activities
    Turn-Taking & Social Skills

    Bubble Conversations: Axolotl creates thought/speech bubbles, user responds using AAC
    Show and Tell: User describes tank changes to axolotl, who responds with questions
    Friend Visits: Other virtual creatures visit, requiring introduction and social protocols
    Emotion Recognition: Axolotl displays various emotions, user identifies and responds appropriately

    Perspective-Taking

    Axolotl's Day: Plan activities from the axolotl's perspective (what would make it happy?)
    Problem Solving: Axolotl presents "problems" (too dark, lonely, etc.) requiring empathetic solutions

## Care & Health Activities
    Executive Function & Planning

    Health Monitoring: Track axolotl's needs (happiness, health, cleanliness) and plan interventions
    Routine Building: Establish daily care routines and follow through consistently
    Emergency Response: Handle "sick" axolotl scenarios requiring multi-step problem solving

## Learning & Memory

    Care Research: Look up facts to better care for pet (information processing)
    Growth Tracking: Monitor development and needs over time
    Skill Building: Learn new care techniques that unlock as user progresses

## Eye-Gaze Solutions for Click-and-Drag 👁️
    Sequential Selection Method

    Select origin: Gaze at item to pick up (highlight appears)
    Confirm selection: Dwell or use switch/button
    Select destination: Look at target location (path shows preview)
    Confirm placement: Dwell to complete action

    Gesture Path Following

    Initiate: Dwell on object to "grab"
    Guide movement: Smooth eye movements create path
    Drop zones: Specific areas that auto-complete when gazed at
    Snap-to-grid: Decorations automatically align to predetermined positions

## Mode Switching

    Touch mode: Full drag capabilities for users who can use touch
    Gaze mode: Simplified placement using predefined positions
    Hybrid mode: Gaze selects, touch/switch confirms and places

    Adaptive Difficulty & Individualization ⚙️
    Motor Skill Levels

    High motor ability: Full drag-and-drop, precise placement, multi-touch gestures
    Limited motor: Larger targets, simplified interactions, alternative input methods
    Eye-gaze only: Grid-based placement, sequential selection, voice commands where available

    Cognitive Adaptation

    Visual complexity: Adjust number of choices, visual clutter, animation speed
    Task complexity: Single-step vs. multi-step activities, with/without prompting
    Memory support: Visual schedules, step-by-step guides, immediate vs. delayed feedback

    Communication Goals Integration

    Symbol practice: Incorporate user's current AAC vocabulary into activities
    Syntax building: Structure activities to practice specific grammar patterns
    Pragmatic skills: Social scenarios that require appropriate communication timing and context

## Data Collection & Progress Tracking 📊
    Embedded Assessment

    Reaction time: Speed of selections and decision-making
    Error patterns: Types of mistakes and self-correction behaviors
    Engagement metrics: Time spent, return visits, preference indicators
    Communication complexity: Growth in message length and vocabulary use

    Therapeutic Goal Alignment

    IEP/TALA objectives: Map activities directly to specific educational goals
    Skill transfer: Track whether virtual pet care skills generalize to real-world scenarios
    Social progress: Monitor improvements in turn-taking, empathy, problem-solving
